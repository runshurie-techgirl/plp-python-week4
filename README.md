# PLP Python Week 4 - Functions

This repository holds my Week 4 assignment on writing functions with `def`, `return`, parameters, and default values.

## Files

- `welcome.py`: One `welcome(name)` function that returns a greeting, called three times instead of repeating code.
- `toolbox.py`: Three small functions: `double`, `is_pass`, and `greet`.

## How to Run

```
python welcome.py
python toolbox.py
```

## Expected Output

`welcome.py`:

```
Hello, Amina! Welcome to PLP.
Hello, Brian! Welcome to PLP.
Hello, Fatuma! Welcome to PLP.
```

`toolbox.py`:

```
14
20
True
False
Hello, Amina!
Habari, Brian!
```

## Reflection

The hardest function to write was `greet`, because it was the only one with a default parameter.
I had to understand that "Hello" is used when no greeting is given, but a value like "Habari" replaces it.
